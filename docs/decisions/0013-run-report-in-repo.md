# 0013 — Every run leaves a report in the repository

[README](../../README.md) · [Decisions](index.md)

**Status:** accepted (2026-11-01)

## Decision
A run ends with a self-contained report at `docs.runs/<date>.md`, and a
summary in the chat.

## Why
Nobody watches an unattended run, and a chat is gone with its session. The
report is how the next run, and the team, learn what changed and what was
left pending.
